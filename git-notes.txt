все что видел 
git restore нужен тип для того что бы отменить измениния которые не комитили (ctrl+z) кароч.
git checkout типа чекать хеш и возращаться к каким то комитам старым или удаленным и можно откатить чет.
HEAD detached это условно режим чтения для комитов, и можно читать измения.
git revert отмена комита.
git switch -c создает ветвь.
git merge объядиняет ветви.
fast-forward по идее сдвиг по ветви работает как merge но разница что не создает тип коммит как делает это merge.
git branch -d прост удаляет ветвь параметр -d===delete.
