все что видел 
git restore нужен тип для того что бы отменить измениния которые не комитили (ctrl+z) кароч.
git checkout типа чекать хеш и возращаться к каким то комитам старым или удаленным и можно откатить чет.
HEAD detached это условно режим чтения для комитов, и можно читать измения.
git revert отмена комита.
git switch -c создает ветвь.
git merge объядиняет ветви.
fast-forward по идее сдвиг по ветви работает как merge но разница что не создает тип коммит как делает это merge.
git branch -d прост удаляет ветвь параметр -d===delete.


конфликт слияние это когда git хз что сохранить при условном недопонимае тимы и просит нас это вручную сделать.

 merge request это прост на запрос объединить ветви и 2 чел смотрит давать разрешение или нет
 ревью нужно что бы давать обратную связь что бы челу могли что то подсказать или поправить или наоборот похвалить его работу 
 кофнлик произошел из за того что на одной и той же строке read me (не только он может быть) написано разные предложения 
 то есть гит не знает какую из веток ему брать как основную так как на обоих написано свое.
 что бы решить кофнликт надо во первых обсудить это с партнером а не делать все самому именно и когда после обсуждения вы договорились к какому то исходу
 челу к которму пришел запрос должен исправить этот кофнликт тем как вы договорись, вы можете написать всю в одну строку через запятую или же сделать на разных строк или вообще удалить
